# Kaal Agent - Autonomous AI Intelligence Core

Kaal Agent is an advanced, autonomous AI assistant built with **SmolAgents**, **Groq (Llama-3.3-70b)**, and **Flask**. Designed for high-performance reasoning and complex multi-step queries, Kaal integrates real-time web execution and deep local-system access into a sleek, immersive UI.

## Features
* **Custom Intelligence Core:** Powered by the elite `llama-3.3-70b-versatile` reasoning engine.
* **Agentic Senses & Tools:**
  * **Tavily Web Search:** Advanced depth scanning for real-time facts.
  * **Happenstance API:** Deep-dive logic for precise human intelligence and networking profiles.
  * **Local Python Execution:** Spawns a built-in sandbox for logical iteration and calculations.
  * **Advanced PDF & Text Parsing:** Ingests local files synchronously for document logic.
* **Glassmorphic UI Engine:** A high-contrast, premium animated web interface utilizing CSS Grid, Phosphor Icons, and LocalStorage for thread persistence.

## Tech Stack
* **Backend:** Python + Flask + SmolAgents
* **Frontend:** Vanilla JS + CSS (High Visibility Dark Mode)
* **LLM Engine:** Groq API

## Setup Instructions
1. Clone this repository.
2. Install the necessary packages.
3. Configure your API keys in the `.env` file (Groq, Tavily, Happenstance).
4. Run `python server.py`.
5. Access the Kaal Agent at `http://127.0.0.1:5000`.
